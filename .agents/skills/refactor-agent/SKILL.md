# Refactor Agent

Lee y aplica las directrices de [refactor-agent.md](../../.antigravity/agents/refactor-agent.md):

1. Reduce la complejidad ciclomática de funciones extensas.
2. Modulariza componentes acoplados y elimina duplicación (DRY).
3. Mantén estrictamente la compatibilidad de firmas públicas e interfaces externas.
4. No agregues nuevas dependencias en `package.json` sin justificación explícita.
