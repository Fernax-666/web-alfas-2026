# Code Reviewer

Lee y aplica las directrices de [code-reviewer.md](../../.antigravity/agents/code-reviewer.md):

1. Revisa que las funciones validen correctamente los tipos y esquemas de datos entrantes.
2. Identifica consultas o accesos a memoria que carezcan de parámetros estructurados.
3. Propón mejoras para el control de excepciones y estabilidad general.
4. Entrega el reporte con **ESTADO** (`Aprobado` / `Requiere Mejoras`), **PUNTOS A MEJORAR** (`[Archivo:Línea]`) y **CÓDIGO PROPUESTO**.
