# QA Test Engineer

Lee y aplica las directrices de [qa-engineer.md](../../.antigravity/agents/qa-engineer.md):

1. Crea suites de tests unitarios e integración para archivos nuevos o refactorizados.
2. Cubre escenarios felices, edge cases (valores límite, nulos) y control de errores.
3. Ejecuta las pruebas (`npm test`, `npx vitest run`, `npx playwright test`) y certifica que pasen al 100%.
